Machine Learning Roadmap — For Data Analysts

Step-by-step plan to move from data analysis → machine learning, with free resources and project ideas.

Overview

Follow these phases in order: Math & Statistics → Python for ML → Core ML Concepts → Projects → Advanced Topics. Use the linked free videos, courses and docs to learn and practice.

Phase 1 — Math & Statistics (1–2 weeks)

  • Linear Algebra basics: vectors, matrices, dot product, transpose
  • Probability & Statistics: distributions, mean, variance, Bayes' theorem
  • Calculus intuition: derivatives and gradients
StatQuest with Josh Starmer (YouTube) Khan Academy — Linear Algebra Khan Academy — Statistics & Probability

Phase 2 — Python for ML (1–2 weeks)

  • NumPy & Pandas for data manipulation
  • Matplotlib & Seaborn for visualization
  • Scikit-learn basics: fit/predict/transform
Kaggle — Intro to Machine Learning Kaggle — Pandas freeCodeCamp — Python for Data Science (Video) Scikit-learn — Getting Started

Phase 3 — Core ML Concepts (3–4 weeks)

  • Supervised: Linear & Logistic Regression, Decision Trees, Random Forests, Gradient Boosting (XGBoost/LightGBM)
  • Unsupervised: K‑Means, Hierarchical Clustering, PCA
  • Model evaluation: train/test split, CV, accuracy, precision, recall, F1, ROC‑AUC
freeCodeCamp — Machine Learning Crash Course (Video) Krish Naik — Machine Learning Playlist (YouTube) Kaggle — Intermediate Machine Learning

Phase 4 — Practical Projects (4–6 weeks ongoing)

Do end‑to‑end projects. Each project should include: EDA, feature engineering, modeling, evaluation, and a short write‑up in a notebook.

  • Retail: Customer churn / sales prediction (classification/regression)
  • Healthcare: Disease prediction (classification)
  • Finance: Regression/time series (price prediction — basic)
  • Recommendation: Collaborative filtering basics
Kaggle Datasets (find project data) Krish Naik — Data Science Projects (YouTube) freeCodeCamp — ML project guides

Phase 5 — Advanced Topics (Optional)

  • Feature engineering & feature selection
  • Hyperparameter tuning (GridSearchCV, RandomizedSearchCV, Optuna)
  • NLP basics and text classification
  • Deep Learning (TensorFlow / PyTorch) — after ML fundamentals
fast.ai — Practical Deep Learning freeCodeCamp — Deep Learning Crash Course (Video)

Practice & Portfolio Tips

  • Use Jupyter Notebooks and document your thought process.
  • Push notebooks to GitHub with clear READMEs.
  • Create short writeups on LinkedIn to summarise project insights.
  • Share dashboards on Tableau Public or simple web apps with Streamlit.
Suggested timeline: Month 1 — foundations; Month 2 — core ML; Month 3 — projects. Adjust based on your pace.
