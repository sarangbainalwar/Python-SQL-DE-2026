📚 Month 1: Mathematics & ML Foundations

Week 1-2: Linear Algebra & Calculus

Essential math for understanding ML algorithms

🧮 Linear Algebra Fundamentals 1 week
YouTube 3Blue1Brown - Essence of Linear Algebra

Visual, intuitive explanations of vectors, matrices, transformations. Best linear algebra series ever created. Watch all 16 videos (3-4 hours total).

YouTube MIT OpenCourseWare - Linear Algebra

Gilbert Strang's legendary course. Watch lectures 1-10 for ML essentials. Deep but worth it.

Website Khan Academy - Linear Algebra

Interactive practice problems. Complete "Vectors and spaces" and "Matrix transformations" sections.

🔧 Practice Tasks:

  • Implement matrix operations in NumPy
  • Solve 10 Khan Academy practice problems daily
  • Visualize vector transformations using Python
📈 Calculus for ML 3-4 days
YouTube 3Blue1Brown - Essence of Calculus

12 video series covering derivatives, chain rule, optimization. Focus on episodes 2, 3, 4, and 6 for ML.

Website Khan Academy - Calculus

Focus on: Derivatives, Chain rule, Partial derivatives, Gradient descent basics.

🔧 Practice Tasks:

  • Calculate gradients manually for simple functions
  • Implement gradient descent from scratch
  • Visualize cost function optimization
